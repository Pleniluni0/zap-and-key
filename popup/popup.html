Dominios configurados
    ⚡ Zap Mode — Borrar elementos
    1. Abre el popup y pulsa ⚡ Zap Mode
    2. Pasa el ratón sobre cualquier elemento — se resalta en rojo
    3. Click para eliminarlo
    4. Aparece un toast «Deshacer» durante 5 segundos
    5. El elemento se oculta para siempre en ese dominio
    6. Pulsa Escape para cancelar

    💡 Puedes pausar reglas por dominio con ⏸️ sin borrarlas.

    ⌨️ Key Bind — Clics con teclas
    1. Abre el popup y pulsa ⌨️ Key Bind
    2. Click en cualquier botón/enlace (ej: "Siguiente")
    3. Superposición azul: "Pulse una tecla para asignar..."
    4. Pulsa una tecla (ej: →, N, F2)
    5. ¡Listo! Esa tecla ahora hace clic en el botón
    6. Mantén Escape 1 segundo sobre un elemento para borrar su atajo

    💡 Los atajos no se disparan mientras escribes en campos de texto.

    🤖 Auto Mode — Lectura sin manos
    1. Ve a la pestaña 🤖 Auto
    2. Configura:
      • Velocidad — 5 niveles (🐢 a 💨)
      • Espera — segundos abajo antes de avanzar
      • Tecla Siguiente — el keybind que pulsa "Next"
      • Atajo — combinación para activar/parar (ej: Ctrl+Shift+A)
    3. Pulsa ▶ Iniciar
    4. La página hace auto-scroll. Al llegar abajo, un badge ⏳ muestra la cuenta atrás
    5. El badge hace clic en "Siguiente" y el scroll se reanuda solo 🔄
    6. Pulsa ■ Parar o haz click en el badge para detener

    💡 Necesitas un keybind asignado al botón "Next" para que funcione el auto-avance.

    📖 Historial — Seguimiento de lectura
    1. Automático — no requiere configuración
    2. Navega por cualquier sitio de cómics/manga con normalidad
    3. La extensión detecta serie y capítulo del título y la URL
    4. Ve a 📖 Historial para ver tu progreso
    5. Agrupado por dominio (click para expandir/colapsar)
    6. Click en cualquier entrada → abre esa página
    7. Usa ✕ para borrar una entrada o 🗑️ para limpiar un dominio
    8. Solo se guardan páginas que parecen un lector de cómics. Si una web no se guarda, entra en 📖 Historial y pulsa ✅ Registrar siempre; si se cuela una que no es un cómic, pulsa 🚫 No registrar (o el 🚫 junto al dominio)

    💡 Soporta español e inglés: "Capítulo", "Chapter", "Ch.", "Episodio", "Ep.", etc.
